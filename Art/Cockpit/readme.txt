Cockpit Art folder.

Fonts:
Contains the 'milspec' font file that looks most like the SR71 text from that era.  This file is used by the Blender resource.blend file.

Objects:
Contains the .blend files from which the cockpit renders are made.

Renders:
Contains the intermediate renders that go into making the final Gimp files, and eventually the .dds files.  This folder should be ignored from git.

render.py: is a ChatGPT generated python script to run Blender and create a render from one of the collections.
